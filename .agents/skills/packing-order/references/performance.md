# 执行、输出与计时

本页是等待、通用失败处理及输出预算的正文。各阶段只补充自己的门槛、检查点和恢复参数。修改文档或离线验证不登录、不写正式业务。

## 正常调度

按阶段加载规则和本轮缓存的 capabilities，不重复枚举或扫描历史。固定助手一次覆盖完整授权范围；本地转换、原程序校验、prepare和异常摘要可顺序合并，任一步失败即停。正式准备、主代理核对和提交分开，依赖写入不预先排队，同一E10会话不并发。

不通过减少分页、抽样、缩小授权集合、跳过原audit/版本/BOM/防重门槛提速。明确零新增直接进入下一合法阶段，不启动空代理或追加确认。表格复用和写前检查只在[钉钉契约](dingtalk-mcp.md#快照生命周期)维护。

## 输出预算

- 完整输入、分页、计划、audit和回执落盘；模型只接收状态、完整性、计数、全部异常类型和产物路径。通常每阶段一条短摘要。哈希从真实文件读取和验证，不手抄长值。
- SessionOutput 保存全部结果，终端只输出白名单摘要。read_sequence 的 summary 用于选择必要原文，不能代替来源、完整校验或业务授权。
- 普通进度最多每30秒一次；失败、unknown、in_flight及最终结果立即输出。进度原文全部保存。正常只等待同一终端，不同时轮询终端、进度文件和逐单回执；异常才定点取证。
- 大表用固定执行器按实际UTF8参数预算落盘，不打印整表、截断、抽样或临时重写传递程序。具体分块与partial规则见钉钉契约。
- 本地交付合并同类工作，异常仅展开受影响字段；原校验已覆盖的正常行不重新逐行核算。

## 停止与恢复

启动长操作记录开始时间，每次等待不超过30秒。**任一调用180秒未返回，或步骤连续180秒没有实际对象、分页或明确检查点完成，立即暂停后续调度并通知用户。** 心跳不重置计时。

通知说明步骤/对象、等待时长、已完成范围、结果是否确定、日志/检查点位置和需要协助的事项。暂停后等待用户明确指示；请求不能取消时只暂停后续调度，不声称远端已停。

失败、超时、中断、unknown/in_flight时保留started、操作ID、检查点及原回执，停止依赖写入。先查操作状态和受影响实际单据/表格范围，区分成功、失败、未知和未尝试项；不自动重试、删除标记、换编号/reference或换目录绕过保护。确认未完成且原因已修复后，才按对应阶段的显式恢复入口接续未完成对象；未知操作不重交，成功对象不重建。

表格异常只补查必要范围；影响重复组或身份时更新该表完整计划。正常提交按实际回执报告，不读回、刷新或运行verify。不关闭用户客户端，不为恢复擅改全局MCP配置。

## 度量边界

比较相同范围、筛选、阶段和时间窗。workflow-timing的命令耗时与mcp-calls的SDK耗时有重叠，不相加；命令间隔还包括本地程序、用户、子代理和其他工具，不能直接归因于模型或ERP。

字符/UTF8字节减少仅证明文本负载减少，无实际token计量不报告token节省百分比；离线验证不证明线上整轮加速，不用正式业务测速。
