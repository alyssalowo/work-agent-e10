# MCP会话异常恢复

仅登录异常、认证失效或业务中断时读取；正常启动和传输按[mcp-session](mcp-session.md)。

## 身份与登录组件

出现登录组件异常时先核对运行用户与凭据文件所有者，不读取或复制凭据内容、不盲目重登；确认此原因后结束未登录会话，按宿主批准机制在本机用户环境显式恢复同一MCP助手，不修改全局MCP配置。

## 认证失效与中断

中断恢复可保留已完成项；存在 `in_flight` 或 `failure` 时先调用状态查询和实际单据查询，不能直接重跑该检查点。

任一准备/查询返回认证失效就停止该组后续请求，保存已完成范围与失败页，显式登录成功后只继续缺少部分。不要把大串请求预先排队，造成同一失效会话连续报错。正式写入未知时先核实实际结果，不能套用只读恢复规则。正常无错误且同轮参数不变时复用已有完整快照，避免为了认证或测速重复查业务、重复展开BOM。

工单控制器恢复见[控制器异常恢复](workorder-branches-recovery.md)。不将只读续查规则套用到保存、审核或追加。
