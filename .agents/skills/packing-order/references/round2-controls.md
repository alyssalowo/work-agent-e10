# 第二轮实施与开放状态

职责以 [subagents.md](subagents.md) 为唯一规则。Sol 正常 medium，Terra 正常 medium，Luna 标准离线 low；外部写入不自动提高强度，具体异常才局部升级。程序已覆盖的正常行不重复交给模型审计。

## 当前实现

- `scripts/restricted_sheet_entry.cjs` 只开放显式 `offline_mock`：绑定宿主授权文档、工作表、允许字段、真实物理表头、计划和写前条件的哈希；现有格匹配优先验证，再验证追加。完整任务还检查真实审核 Y 与前序逐步成功回执。缺件、越权、落盘失败、unknown 和部分成功均阻断；started 独占记录防止自动重放。
- 零新增阶段同样可以接续，但必须绑定三来源完整、经固定程序重新构建的空追加计划和对应零操作回执；单独声明“零新增成功”不能放行。离线入口中的重建产物由受信宿主提供，不能当作已接通的线上验证器。
- `createLiveEntry` 始终拒绝开放。当前宿主子代理没有已验证的工具允许列表，可能继承 E10 工具，不能借提示词、离线 mock 或本地文件权限宣称已隔离。主代理继续执行已授权正式业务；Terra 只能做离线准备。开放必须先证明子代理无法绕过入口调用 E10 或范围外钉钉能力，随后验证真实受限传输。
- `source_evidence.py` 和 `shipment_append_plan.py` 校验原始请求/响应分页、三来源/独立限定范围、字段/状态选项元数据及完整计划重建；提交前再次复验。销货作废整单排除和借出已结束原因优先级已固化。
- [按需读取](sheet-read-plan.md) 已接入普通表采集器；同轮缓存绑定原始文件并重验范围。成功回执继续按原投影契约接续。局部补查只输出恢复证据，不自动解除阻断。
- 原始来源与字段元数据适配采用严格文件契约。真实宿主返回不能满足该契约时会停止；本轮未连接业务系统验证适配，不能将合成样本通过解释为线上兼容性已验收。

## 离线验收与实际用量

仓库测试只用合成数据和模拟提交，覆盖原业务规则、缺来源、缺审核/回执、权限越界、证据篡改、未知提交及失败恢复。通过不表示真实业务完成、工具权限隔离完成或线上条件更新具有原子性。

[用量记录器](usage-comparison.md) 保存实际额度、模型/强度、子代理次数、MCP 读写、返工及完成质量；缺真实额度时记 null，不从 token 或任务耗时推算。本轮没有优化前后同类完整合格业务任务的真实额度基线，尚不能给出节省比例。正式运行前后按同口径留存数据再对照。现阶段减少重复采集与重复模型审计的规则和程序已落地，实际额度收益仍待测量。
